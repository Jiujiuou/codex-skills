# 品牌、图形与布局

## 品牌配置

颜色集中在 CSS tokens，涵盖背景、正文、辅助文字、描边、图表和 JS 动画终态。改主题时同时检查内联 SVG、marker、行内样式及 GSAP 中硬编码颜色。

以下是从 Wahda 项目整理的可选预设；官网样式会变化，后续用户要求当前官方风格时重新读取原始资源。

| token | 示例值 | 用途 |
| --- | --- | --- |
| primary | `#3545D6` | 主蓝、标题和关系线 |
| secondary | `#5363EE` | 次级蓝、分层边框 |
| accent | `#C2F74F` | 荧光绿高亮和大色块 |
| ink | `#0E1A27` | 正文 |
| muted | `#64748B` | 辅助文字 |
| paper | `#F9FAFB` | 页面背景 |
| cool | `#EEF0FD` | 浅蓝底板 |
| olive | `#72912E` | 白底上的绿色线条和小字候选 |

来源：https://wahda.com/；官方 Logo：https://wahda.com/brand-gram.png。Logo 使用原始文件与比例，不从展示截图反推路径。荧光绿配深色文字通常更合适，小字不能只凭视觉判断对比度。

## 首屏元素

围绕主标题布置少量无文字的浏览器轮廓、消息气泡或节点组合。预留标题安全区；装饰设置 `pointer-events: none`、`aria-hidden`。位置要根据宽高调整，短屏减少数量。品牌 Logo 应保持原貌，创意动画作用于外围图形。

## 箭头

每条关系用一个 cubic Bezier `M ... C ...`。起终点设在节点边界外 6–10 个 SVG 单位，控制点决定弧度与入射方向。默认虚线例如 `5 6`，聚焦可增加线宽；正常态和聚焦态使用品牌色。marker 尺寸和 `refX` 要与实际端点一起检查。

需要经过说明文字时优先调整标签位置，让曲线走开放空间。一条曲线跨过多张卡时可能需要改排版或换端口，不能用大弧度绕出可视区域作为通用修补。

## 宽屏居中

两个区域高度不同，计算各自内容（含标签、连线、底部说明）的 minY/maxY，按中心差平移较短区域。连接线、节点、标签一起平移，最好包在同一个 group 中。

CSS 网格子项使用 `min-width: 0; min-height: 0`，舞台尺寸明确。SVG `viewBox`、`preserveAspectRatio`、容器 padding 都影响实际可见区域。不要只按屏幕长宽比推算镜头。
