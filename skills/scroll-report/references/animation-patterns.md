# 动画模式与接线

## 输入与播放分开

`scrub` 将动画进度直接绑定滚动距离，鼠标速度会改变观感。演讲时希望速度固定，使用暂停时间线加 `play()` / `tweenTo()`，或返回完成 Promise 的过渡函数。一个手势选择下一状态，时间参数决定播放速度。

`assets/report-motion.js` 提供：

- `gestureRouter(resolve, options)`：统一 wheel、触摸和上下翻页键。`resolve(direction)` 返回可执行的任务或 `null`；只有任务接管时才阻止自然滚动。任务 Promise 完成后保留短暂惯性隔离。`destroy()` 取消并移除监听器，停止尚在执行的受控动画。
- `scrollToElement(element, seconds, signal)`：按固定时间滚动到章节，支持中止。
- `slides(cards, index, seconds, signal)`：卡片在固定区域水平滑入滑出。列表应是数组。
- `focus(items, index, seconds, signal)`：`index = -1` 恢复总览；其他状态突出一层并减弱其余层。
- `expandGrid(grid)`：创建独立覆盖卡，不改变原始网格布局；`show(index, seconds, signal)` 先收回当前覆盖卡，再从目标原始位置展开。`index = -1` 回总览，`destroy()` 清除临时节点。
- `diagram(svg, camera, targets, padding)`：用 viewBox 中的目标边界计算镜头；`show(null, ...)` 回总览。目标是 camera 内同一坐标系下的图形包围框；必要时先合并节点与说明边界。

这些函数是可修改的起点；不要在已有页面未审查输入控制和几何结构时直接全部注入。示例在屏幕宽高足够时才启用，并在 `gsap.matchMedia` 的清理函数中移除监听器、覆盖节点和行内状态。

## 五种模式的状态

### 封面转场

将圆环/装饰、标题和 Logo 放入同一中心坐标。圆环缩小并改变圆角，Logo 在原位置显现。避免把「圆环变 Logo」写成一个新图标从下方飞入。播放完成可接一段定时翻页。

示例时间：聚合 1.6 秒 → Logo 停留 0.5 秒 → 翻页 1.3 秒。它们是起点，不是品牌规范或强制标准。

### 横向摘要

`currentIndex` 独立于页面滚动位置。一张卡片讲完再接受下一次手势。出口规则：首张向上返回上一章；末张向下进入下一章。两张卡片同时移动，避免先把当前卡完全隐藏后才显示下一张。

### 分层架构

`[-1, 0, 1, ... , N-1, -1]`；保留标题和整个结构的定位。聚焦通过透明度、描边或轻微缩放即可。别用不必要的数据流编排掩盖讲解顺序。

### 关系图

状态数据可用 `{nodeIds, edgeIds, labelIds}`。在 SVG 内统一变换 camera，别分别挪动节点和连线。取目标联合包围框，加入留白后用两轴中的最小缩放比；上下居中时也要考虑说明标签。

示例的镜头函数假设 SVG viewBox 与 camera 图形坐标一致、没有嵌套变换；复杂图形应先将边界转换到同一坐标系。窄屏可回到整体 SVG 或自然横向浏览。

### 网格展开

覆盖卡复制当前卡的外观，先在原卡位置初始化，然后同时改变 x/y/宽/高/内边距。不要只做 `scaleX`、`scaleY`，否则文字会拉伸。文本可单独调整字号，但注意换行带来的跳动。

覆盖卡用不透明背景，展开区域等于整个网格；文字应继续保留在原始卡内，覆盖副本 `aria-hidden`。标识目标原卡，避免键盘焦点落到隐藏内容；有链接/按钮的卡需要单独处理交互语义，不能直接复制可交互元素作为纯装饰。

## 不要复制的旧实现方式

- 用几个章节各自的全局 wheel 监听器互相争夺控制。
- 让滚动吸附、`scrub` 和独立播放同时修改一条时间线。
- 为了曲线效果，对直角路线切成碎段后插值；每条关系应从起点到终点直接定义控制点。
- 为了方便，把整份含业务事实的汇报文件当通用模板上传。
